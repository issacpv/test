# Computational Biomedical Engineering Project Portfolio

**113 scaffolded research projects** built on open biomedical datasets (OpenNeuro, HCP, Allen Brain Atlas, NeuroMorpho.org, OASIS, DANDI, CHB-MIT, openFDA, MIMIC-IV and ~150 others — see [`DATASETS.md`](DATASETS.md)). Each project targets a specific, literature-checked gap with a publishable angle, and ships as a self-contained folder ready to become its own repository.

## What every project contains

| File | Purpose |
|---|---|
| `README.md` | Background, **the research gap** (with key papers), numbered hypotheses, dataset table with access level, methods, evaluation & statistics (leakage prevention, nulls, multiple comparisons), publishable angle + target venues, risks/confounds, milestones, ethics/data-use notes |
| `data/README.md` | Exact step-by-step data acquisition (real APIs/CLIs: openneuro-py/DataLad, dandi, allensdk, NeuroMorpho REST, openFDA, PhysioNet wget, XNAT, S3) and expected layout |
| `scripts/download_data.py` | Working downloader for open parts (with `--sample`/`--dry-run` modes); credentialed sources read credentials from env vars |
| `src/<package>/` | 3–6 real starter modules (loaders, feature extraction, core statistic/model, null models, evaluation) with docstrings and type hints |
| `tests/` | Synthetic-data tests exercising the core functions (`PYTHONPATH=src pytest`) |
| `requirements.txt`, `.gitignore` | Pinned-ish deps; data/outputs never committed |

## Turning folders into repositories

```bash
git clone <this-repo> && cd <this-repo>
tools/split_into_repos.sh                  # one local git repo per project under ../bme-projects/
tools/split_into_repos.sh --github <user>  # also create (private) GitHub repos via `gh`
```

## Access levels

**Open** = no registration · **Reg** = free account · **DUA** = free data-use agreement · **Cred** = PhysioNet credentialed (CITI training + DUA) · **App** = formal application (NDA, LONI, CDAS) · **License** = licensed ontology (MedDRA, DrugBank academic)

> PhysioNet credentialed data (MIMIC, eICU, HiRID, MIMIC-CXR …) must **never** be sent to third-party LLM APIs; the projects that touch text ship local-only model wrappers. Never commit data.

## Verification status

Every `.py` file compiles and every project's synthetic-data test suite passes (see the ✅ column; ⚠️ marks projects with a known non-blocking issue noted at the bottom). Literature checks were run against 2023–2026 papers; because the sandbox's web-search budget and some publisher sites were limited, a minority of very recent papers are cited by title/venue/year without full author lists, and READMEs flag specific facts (dataset sizes, accession IDs, API paths) to re-verify before use. **No citations or DOIs were invented.**

## Abstracts

[`ABSTRACTS.md`](ABSTRACTS.md) holds a ~2,500-character structured abstract for every project (also at `projects/<slug>/ABSTRACT.md`), each checked against the nearest 2023–2026 papers and rewritten where a claim was already taken.

## Literature check

`tools/litcheck.py` queries Europe PMC, PubMed, arXiv and Crossref (OpenAlex / Semantic Scholar when keys are set) with curated queries per project, scores papers by key-term coverage and walks the citation neighbourhood. Results: [`litcheck/SUMMARY.md`](litcheck/SUMMARY.md) (all 113 ranked by near-miss risk) and [`litcheck/VERDICTS.md`](litcheck/VERDICTS.md) and [`litcheck/VERDICTS2.md`](litcheck/VERDICTS2.md) (deep-read verdicts for all 113 projects: 0 closed, 31 narrowed with abstracts rewritten, 82 open). Re-run with `CROSSREF_MAILTO=you@example.org python tools/litcheck.py`.

## Suggested ways to prioritise

1. **Zero-access-friction first**: projects whose datasets are all *Open* (openFDA, NeuroMorpho, Allen, DANDI, OpenNeuro, PTB-XL, CHB-MIT) can start today.
2. **Apply early** for HCP Restricted, NDA (HCP-Aging/-Development, ABCD, OAI), LONI (ADNI/A4), NSRR, and PhysioNet credentialing — several projects are blocked only on these.
3. **Methods audits** (nulls, multiverses, leakage, transportability, label-definition sensitivity) are the fastest route to a paper because they reuse public results and need no new data collection.
