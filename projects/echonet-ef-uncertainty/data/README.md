# Data acquisition

Every echo dataset used here requires registration and/or a data-use agreement; none can be
fetched anonymously, so `scripts/download_data.py` (a) generates a synthetic smoke-test set,
(b) verifies a local layout, and (c) downloads CAMUS when you supply the URL you receive after
registering. Nothing under `data/` is committed.

Expected layout:

```
data/
  echonet-dynamic/                # Stanford AIMI (DUA)
    FileList.csv                  # FileName, EF, ESV, EDV, FrameHeight, FrameWidth, FPS, NumberOfFrames, Split
    VolumeTracings.csv            # FileName, X1, Y1, X2, Y2, Frame  (LV tracings at ED/ES)
    Videos/0X1A0A263B22CCD966.avi ...
  echonet-pediatric/              # Stanford AIMI (DUA)
    A4C/FileList.csv, A4C/VolumeTracings.csv, A4C/Videos/*.avi
    PSAX/FileList.csv, PSAX/VolumeTracings.csv, PSAX/Videos/*.avi
  echonet-lvh/                    # Stanford AIMI (DUA); PLAX videos, MeasurementsList.csv
    MeasurementsList.csv, Batch1/*.avi ...
  camus/                          # Creatis (registration)
    training/patient0001/patient0001_4CH_sequence.mhd/.raw, _2CH_..., Info_4CH.cfg (EF, ImageQuality, ED, ES)
    testing/patient0451/...
  tmed2/                          # Tufts (DUA)
    labeled/*.png, DEV479/*.csv (view + diagnosis labels), unlabeled/...
  synthetic/                      # generated by --sample (no real data)
```

## EchoNet-Dynamic, EchoNet-Pediatric, EchoNet-LVH (Stanford)

1. Go to https://echonet.github.io/dynamic/ (Pediatric: https://echonet.github.io/pediatric/, LVH: https://echonet.github.io/lvh/).
2. Click "Access the dataset", register on the Stanford AIMI shared-datasets portal and accept the research use agreement.
3. You receive a download link (zip, ~7 GB for Dynamic). Unzip into `data/echonet-dynamic/` so that `FileList.csv` is at that level.

`FileList.csv` `Split` column defines the official TRAIN/VAL/TEST partition; use VAL as the conformal calibration set.
Videos are 112x112 grey-scale AVI at ~50 fps. Citation: Ouyang D. et al., Nature 2020; Reddy C.D. et al., JASE 2023; Duffy G. et al., JAMA Cardiol 2022.

## CAMUS (Creatis, Lyon)

1. Register at https://www.creatis.insa-lyon.fr/Challenge/camus/ (or the "humanheart-project" data portal linked there).
2. After approval you receive a download URL for the archive. Then:

```bash
export CAMUS_URL='https://.../CAMUS_public.zip'     # the URL from your registration e-mail
python scripts/download_data.py --dataset camus --out data
```

Each patient folder contains `_2CH` and `_4CH` sequences (`.mhd/.raw`), ED/ES masks (`_ED_gt`, `_ES_gt`) and `Info_*CH.cfg` with `EF`, `ImageQuality` (Good/Medium/Poor), `ED`, `ES`, `NbFrame`, `Sex`, `Age`. Citation: Leclerc S. et al., IEEE TMI 2019.

## TMED-2 (Tufts)

1. Request access at https://tmed.cs.tufts.edu/tmed_v2.html (data use agreement).
2. Unzip into `data/tmed2/`. Labels: view (PLAX, PSAX, A2C, A4C, Other) and aortic-stenosis severity per study; no EF.
Citation: Huang Z. et al., "TMED 2: a dataset for semi-supervised classification of echocardiograms", DataPerf @ ICML 2022.

## Synthetic smoke-test set (no registration)

```bash
python scripts/download_data.py --sample --out data     # writes data/synthetic/{FileList.csv,Videos/*.npz} with known EF
python scripts/download_data.py --verify --out data
```

The synthetic videos are beating ellipsoids rendered as 112x112 frames with analytic EF, used only to exercise the
loader, Simpson's method and the conformal harness end-to-end.
