# Data acquisition

Nothing under `data/` is committed except this file. All commands run from the project root.
Both real databases are PhysioNet **credentialed** resources; the semi-synthetic cohort is the only
open part and is generated locally.

Expected final layout:

```
data/
  synthetic/                       # generated by scripts/download_data.py --simulate (open)
    long_gamma{g}_site{s}.parquet, stays_gamma{g}_site{s}.parquet
  mimiciv/3.1/
    hosp/
      patients.csv.gz  admissions.csv.gz  d_labitems.csv.gz
      labevents.csv.gz   (~2.5 GB gz; 13 GB raw; has priority, storetime, order_provider_id)
      poe.csv.gz         (provider order entry; order_type = 'Lab' gives lab *order* times)
      poe_detail.csv.gz
    icu/
      icustays.csv.gz  d_items.csv.gz
      chartevents.csv.gz (optional, only for vitals covariates; ~3 GB gz)
      inputevents.csv.gz (optional, vasopressor covariates)
  eicu/2.0/
    patient.csv.gz  hospital.csv.gz  lab.csv.gz  apachePatientResult.csv.gz
    (optional) vitalPeriodic.csv.gz for vitals covariates
```

## 1. Semi-synthetic cohort (open, no account)

```bash
python scripts/download_data.py --simulate --out data/synthetic --n-stays 2000 --gammas 0 1 2 --site-shifts 0 -1.5
```

writes long/stays parquet (or CSV if pyarrow is missing) for each (gamma, site shift) so the
attribution and thinning pipeline can be exercised end-to-end without credentials.

## 2. MIMIC-IV v3.1 (PhysioNet credentialed)

1. Create a PhysioNet account, complete CITI "Data or Specimens Only Research", and sign the DUA
   for **MIMIC-IV** (https://physionet.org/content/mimiciv/3.1/).
2. Export credentials (never write them into committed files):

```bash
export PHYSIONET_USERNAME=your_user
export PHYSIONET_PASSWORD='your_password'
```

3. Download only the files this project uses:

```bash
python scripts/download_data.py --dataset mimiciv --out data/mimiciv/3.1
# equivalent wget for one file:
wget -N --user "$PHYSIONET_USERNAME" --password "$PHYSIONET_PASSWORD" -P data/mimiciv/3.1/hosp \
  https://physionet.org/files/mimiciv/3.1/hosp/labevents.csv.gz
```

Key columns: `labevents.priority` ('STAT'/'ROUTINE'), `labevents.charttime` (specimen collection),
`labevents.storetime` (result available), `poe.ordertime` with `poe.order_type = 'Lab'`,
`patients.anchor_year_group` (era), `admissions.race/insurance/language`. Hour of day is preserved
by the MIMIC-IV date shift (confirm in the MIMIC-IV documentation for your version before relying on
day-of-week).

## 3. eICU-CRD v2.0 (PhysioNet credentialed)

Sign the eICU-CRD DUA (https://physionet.org/content/eicu-crd/2.0/), then:

```bash
python scripts/download_data.py --dataset eicu --out data/eicu/2.0
```

Key columns: `lab.labname`, `lab.labresultoffset` (minutes from unit admission), `patient.hospitalid`,
`patient.unitadmittime24` (clock time of admission, gives hour of day), `hospital.numbedscategory`,
`hospital.teachingstatus`, `hospital.region`. eICU has no STAT flag, so priority-based features are
MIMIC-IV only.

## 4. Verify

```bash
python scripts/download_data.py --verify --out data
```

prints which files are present and, if `duckdb` is installed, the row counts of `labevents`/`lab`.
