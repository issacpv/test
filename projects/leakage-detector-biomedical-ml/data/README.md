# Data acquisition: the audit corpus

The "data" are public code repositories linked to published biomedical ML papers, plus the paper metadata needed to relate detected leakage to reported performance. Nothing in this folder is committed except this file. No biosignal data are needed for the audit itself; the *dynamic confirmation* step (re-running a subset of repos with subject-wise splits) uses the open datasets documented in the sibling projects (`cross-dataset-seizure-generalization`, `ecg-cross-dataset-generalization`).

## Expected layout

```
data/
  corpus/
    chbmit_repos.csv            # GitHub search hits (full_name, html_url, stars, created_at, pushed_at, language, query, dataset)
    ptbxl_repos.csv
    mimic_repos.csv
    ptbxl_citing_papers.csv     # Semantic Scholar citations of the dataset descriptor + GitHub links found
    paper_repo_links.csv        # curated: doi, full_name, dataset, reported_metric, reported_value, split_claimed (manual)
    annotations/                # manual ground truth for the detector evaluation
      sample_100.csv            # repo, file, rule, annotator_A, annotator_B, adjudicated
  repos/
    <owner>__<repo>/            # shallow clones (git clone --depth 1)
  mutation_corpus/              # generated by scripts (clean pipelines + injected leakage variants)
```

## 1. GitHub search (repository and code search)

Create a fine-grained personal access token with *public repositories (read-only)* scope at https://github.com/settings/tokens and export it:

```bash
export GITHUB_TOKEN=github_pat_...
python scripts/download_data.py --dataset chbmit --max-pages 10          # repository search, ~1,000-result cap per query
python scripts/download_data.py --dataset ptbxl --code-search            # code search: files containing "ptbxl_database.csv"
python scripts/download_data.py --dataset mimic --code-search
```

Rate limits: search is 30 requests/min authenticated (10/min unauthenticated); the script sleeps on `403`/`429` until `X-RateLimit-Reset`. Repository search without a token works for `--sample`.

The query phrases per dataset are in `leakscan.corpus.DATASET_QUERIES`; extend them (e.g. `"SC4001E0-PSG.edf"` for Sleep-EDF, `"data_preprocessed_python"` for DEAP) and re-run; results are merged and de-duplicated by `full_name`.

## 2. Paper -> repository links (Semantic Scholar)

The Semantic Scholar Graph API (https://api.semanticscholar.org/) returns every paper citing a dataset descriptor with abstract and open-access PDF URL:

```bash
export S2_API_KEY=...            # optional; raises the rate limit (request at https://www.semanticscholar.org/product/api)
python scripts/download_data.py --citations ptbxl --limit 2000
```

Abstracts are regex-mined for GitHub URLs (`leakscan.corpus.extract_repo_links`). Most links live in the full text: download the open-access PDFs listed in `*_citing_papers.csv` and run the same regex on the extracted text (`pymupdf` is listed as an optional dependency). Record the curated paper -> repo mapping in `data/corpus/paper_repo_links.csv` together with the headline metric the paper reports (metric name, value, dataset, and the split the paper *claims*: "random", "record-wise", "subject-wise", "official folds", "not stated"). Two annotators, adjudicate disagreements.

Descriptor DOIs used (from `leakscan.corpus.DATASET_DOIS`): PTB-XL (Wagner et al., 2020, Sci Data), MIMIC-IV (Johnson et al., 2023, Sci Data), eICU-CRD (Pollard et al., 2018, Sci Data), Helsinki neonatal EEG (Stevenson et al., 2019, Sci Data). CHB-MIT has no journal descriptor: use citations of the PhysioNet resource page and of Shoeb (2009) via a title search, and the GitHub route.

## 3. Cloning

```bash
python scripts/download_data.py --clone data/corpus/chbmit_repos.csv
```

Shallow clones (`--depth 1`) into `data/repos/<owner>__<repo>`. Expect ~50-500 MB per 100 repositories; large repos that vendor data are skipped by the 2 MB per-file limit in the scanner, not by the clone. Never run code from cloned repositories.

## 4. Running the audit

```bash
PYTHONPATH=src python -m leakscan audit data/corpus/chbmit_repos.csv --clones data/repos --out outputs/chbmit/findings.csv
PYTHONPATH=src python -m leakscan scan data/repos/owner__repo --md outputs/owner__repo.md
```

## 5. Ground truth for evaluating the detector

- **Mutation corpus** (automatic): take 20 clean pipelines (from this repo's tests and the sibling projects), inject each leakage type by templated edits (move scaler fit above the split; drop `groups=`; pass `X_test` to `validation_data`; add SMOTE before split) and record the injected labels. Precision/recall per rule are computed against these labels.
- **Manual sample** (100 repos, stratified by dataset): two annotators label each repository for each rule with the file/line, blind to the detector output; Cohen's kappa reported; adjudicated labels are the reference for real-world precision/recall.

## Licences and ethics

Public GitHub code is analysed under each repository's licence; only aggregate statistics and rule counts are published. Repositories are identified in the released tables only by an anonymised id unless the authors consent; the mapping is kept in `data/corpus/` and not committed. No patient data are downloaded by this project.
