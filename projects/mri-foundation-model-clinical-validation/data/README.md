# Data acquisition — mri-foundation-model-clinical-validation

Nothing under `data/` is committed. Open datasets are scripted; DUA datasets have manual steps.

## Open, scripted

### MR-ART (OpenNeuro ds004173; paired clean/motion T1w)

```bash
python scripts/download_data.py --mrart            # full (~10 GB)
python scripts/download_data.py --mrart --sample   # 3 subjects
```

Uses anonymous S3 (`s3://openneuro.org/ds004173`) via boto3, or falls back to the OpenNeuro snapshot file URLs. Files: `sub-XXX/anat/sub-XXX_acq-standard_T1w.nii.gz`, `_acq-headmotion1_`, `_acq-headmotion2_`, plus `participants.tsv` and the expert quality scores.

### MindBoggle-101 (manual DKT cortical labels)

Download the "MindBoggle-101 manually labeled individual brains" archives from https://osf.io/nhtur/ (OSF; also mirrored at https://mindboggle.info/data.html). `python scripts/download_data.py --mindboggle` fetches the OSF archive listing via the OSF API (`https://api.osf.io/v2/nodes/nhtur/files/osfstorage/`) and downloads it. Layout: `data/mindboggle101/<subject>/t1weighted.nii.gz`, `labels.DKT31.manual.nii.gz`.

### ISLES 2022 (Zenodo, CC BY)

```bash
python scripts/download_data.py --isles22     # zenodo record 7153326
```

### Shifts 2.0 MS lesion track

Follow https://github.com/Shifts-Project/shifts (data on Zenodo with CC BY-NC-SA); place under `data/shifts_ms/`.

### M4Raw (0.3 T)

https://github.com/mylyu/M4Raw links to the Zenodo records (raw k-space + reconstructions); place reconstructions under `data/m4raw/`.

## Registration / DUA

### CANDI Share

Register on NITRC (https://www.nitrc.org/projects/candi_share/), download the `SchizBull_2008` archives (T1 + manual segmentations); `data/candi/`.

### Hammers adult atlases

Request at https://brain-development.org/brain-atlases/ (free for research); `data/hammers/`.

### ATLAS v2.0 (stroke)

Sign the INDI DUA at https://fcon_1000.projects.nitrc.org/indi/retro/atlas.html; you receive an encrypted archive and password. `data/atlas2/Training/R001/sub-r001s001/ses-1/anat/*_T1w.nii.gz` and `*_label-L_desc-T1lesion_mask.nii.gz`.

### BraTS 2023 (adult glioma + BraTS-Africa)

Register on Synapse (https://www.synapse.org/brats2023), accept terms, download `BraTS2023-GLI` and `BraTS2023-SSA` training sets; `data/brats2023/GLI/`, `data/brats2023/SSA/`.

### OASIS-3 / OASIS-4

NITRC DUA (https://www.nitrc.org/projects/oasis3/, https://www.nitrc.org/projects/oasis4/), then XNAT Central with `XNAT_USER`/`XNAT_PASS`; use https://github.com/NrgXnat/oasis-scripts (`download_oasis_scans.sh`, `download_freesurfer.sh`). `data/oasis3/`, `data/oasis4/`.

## IQMs

Run MRIQC on every T1w input (see `mriqc-scannability-equity/data/README.md` in this repository for the container command) and place `group_T1w.tsv` under `data/mriqc/<dataset>/`.

## Sample mode without network

`python scripts/download_data.py --synthetic` writes a few synthetic phantom volumes and label maps (`data/sample/`) generated by `fm_clinical_val.degradations.make_phantom` so that the metrics/stratification code can be exercised.
