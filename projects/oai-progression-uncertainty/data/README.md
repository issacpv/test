# Data acquisition

OAI has no fully open component; everything below requires (free) registration. Expected layout (nothing committed):

```
data/
  oai/
    clinical/                 # AllClinical00.txt ... AllClinical10.txt, Enrollees.txt, Outcomes99.txt
    xray_readings/            # kXR_SQ_BU00.txt ... (KL, JSN, osteophytes; reader/adjudication fields)
    mri_readings/             # kMRI_SQ_MOAKS_*.txt where used
    images/
      xray/<visit>/<ID>/...   # bilateral PA fixed-flexion DICOM
      mri/<visit>/<ID>/...    # sagittal DESS / IW-TSE DICOM (subset)
  most/                       # MOST clinical + radiographs after approval
  oai_zib/                    # 507 DESS segmentations (open) from ZIB
  mendeley_kl/                # open KL-graded crops for smoke tests
  synthetic/                  # generated by scripts/download_data.py --sample
  derived/
    knee_cohort.parquet       # one row per knee: baseline features, event type, event time
```

## 1. OAI via the NIMH Data Archive (NDA)

Access level: free registration + acceptance of the OAI data access terms ("NDA-lite"). Steps (verified against the NDA OAI page description; re-check for changes):

1. Go to https://nda.nih.gov/oai and log in through the Research Auth Service (RAS) using an eRA Commons account, a Login.gov account, or PIV/CAC.
2. Create an NDA account or link an existing one, then agree to the OAI data access terms.
3. Clinical datasets: download the OAI "ASCII" or SAS packages (AllClinicalXX, Enrollees, Outcomes99, kXR_SQ_BUXX, MRI readings) from the OAI data page and extract to `data/oai/clinical/` and `data/oai/xray_readings/`.
4. Images: create a data package in NDA for the image collection you need (radiograph series first), then use nda-tools:

```
pip install nda-tools
export NDA_USERNAME=...     # never commit
downloadcmd -dp <packageID> -d data/oai/images -u "$NDA_USERNAME"   # prompts for password / uses keyring
```

`python scripts/download_data.py --check-nda` confirms nda-tools and environment variables are in place and prints the list of OAI files the pipeline expects.

## 2. MOST (external validation)

Apply at https://most.ucsf.edu (project description + data-use agreement). After approval, place clinical tables and radiograph exports under `data/most/`.

## 3. Open helpers

- OAI-ZIB segmentations (507 DESS MRIs): https://pubdata.zib.de (search "OAI-ZIB"); images themselves come from OAI.
- Mendeley Data "Knee Osteoarthritis Severity Grading Dataset" (Chen, 2018): open KL-labelled crops derived from OAI for a radiograph-encoder smoke test; download manually into `data/mendeley_kl/`.

## 4. Synthetic sample (offline development)

```
python scripts/download_data.py --sample
```

Writes `data/synthetic/{kl_readings.csv, tkr.csv, followup.csv}` generated by `oai_prog.cohort.simulate_oai_like` so that cohort construction, competing-risk coding and the evaluation code can run end-to-end without OAI access.
